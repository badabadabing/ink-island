# INK ISLAND 墨岛

纸白墨线画风的浏览器单人大逃杀。从「墨线突击」派生：同一套排线着色器、纸模士兵、固定弹道枪械与合成音效，换成一座 480 m 的小岛、跳伞、搜刮、蓝圈和 23 个 Bot。

- **一局流程**：飞机沿随机航线飞过岛 → 空格跳伞（55 m 自动开伞）→ 落地搜刮 → 蓝圈七次收缩 → 最后一人「大吉大利 · 岛上只剩你」
- **据点**：军械库、晒纸场、灯塔渔村、墨池农庄、山顶观测站、废弃印厂，各有楼层、楼梯、门窗与室内掩体
- **物资**：7 把枪（含狙击）、6 种口径弹药、三级纸甲/纸盔/书包、绷带/急救包/止痛药、2x/4x 镜；每 110 秒一个空投（红烟）
- **视角**：第三人称肩后相机，按住右键推到眼位切第一人称瞄准
- **Bot**：各自选落点跳伞，落地搜刮 → 向白圈转移 → 守圈，受伤会找掩体和包扎，毒圈来了会跑

## 运行

```bash
python3 -m http.server 8766
```

打开 http://localhost:8766 （Chrome / Safari；指针锁定需要真实浏览器）。URL 加 `?auto` 跳过指针锁定（调试用）。

## 操作

手机：左半屏摇杆，右半屏滑动转视角，右侧纸钮开火/瞄准/跳/拾取等；桌面加 `?touch` 可预览触控布局。菜单「画质」省电档适合手机。


WASD 移动 · SHIFT 静步 · C 蹲 · 空格 跳 / 跳伞 / 开伞 · 左键 开火 · 右键按住 瞄准 · R 换弹 · F 拾取 · TAB 背包 · 7/8/9 绷带/急救包/止痛药 · 1/2/3 切枪 · M 全图 · ESC 暂停

## 开发

- 纯静态，零外部依赖（three.js r160、线条 addons、字体都在 `vendor/`），无构建。
- 语法检查：`for f in js/*.js; do node --check $f; done`
- 冒烟：`node tools/smoke.js`（无头浏览器快进一整局，输出 `SMOKE OK`）
