墨岛 INK ISLAND · 九个美术换皮方向

三位美术总监各提三案 · 示意图用各案自己的调色板与着色方式画同一处岸边据点（左屋 / 右平顶楼 / 灯塔 / 吉普 / 两名士兵）

1

椰糖海盐总监 A · 晒褪色的热带明信片

  • 暖奶糖底、低饱和，两阶 toon，暗面往墨蓝偏而不发灰，不描边
  • 人物 5.5 头身圆润；脸是两点眼 + 腮红色块；帽巾 / 背心 / 裤三件套色区分阵营
  • 屋顶厚梯形色块（赤陶红 / 海盐白），墙底一道「潮湿带」；棒棒糖树 + 六片菱形棕榈；灯塔红白带
  • 实现：MeshToonMaterial + 3 阶渐变图，无后处理，手机 ≥55 fps。风险：对比柔，远敌靠橙色标记
2

潮汐警戒总监 A · 仍在运作的海岛工业站

  • 冷灰蓝底 + 信号黄 / 警报红两点亮色；平涂 + 半兰伯特过渡，叠丝网颗粒
  • 人物 6 头身方肩方腿，像有体积的安全标识小人；脸是护目镜 / 口罩色块；反光背心斜条纹分阵营
  • 屋顶波纹铁皮 + 黄边，门窗黄色「安全框」；黄黑条纹只用在栏杆 / 路障；方头立方树冠
  • 实现：Lambert + onBeforeCompile 颗粒与条纹，脚下椭圆影，最省，≥60 fps。风险：度假感弱
3

琉璃釉岛总监 A · 手绘陶瓷釉彩，光会晕开

  • 釉白底 + 釉橘 / 葡萄紫；柔和渐变 + Fresnel 釉光亮边，暗面往紫偏，阴影是半透明紫
  • 人物 5 头身陶偶：头略大、四肢圆柱，两点眼 + 弧形腮红；围巾 / 裤脚色带 / 背包形状区分
  • 屋顶加半圆柱顶盖显圆润，釉橘 / 青瓷两色；墙顶一圈亮边；双层球树冠上亮下深；晒纸场挂彩釉片
  • 实现：Lambert + onBeforeCompile Fresnel，一张阴影图（手机改 blob），≥50 fps。风险：盒体上亮边硬跳变
4

陶土定格岛总监 B · 手捏黏土的棚拍海岛

  • 哑光黏土 + 定格感：3 阶 toon，片元加低频噪声做「指纹捏痕」，法线微扰动，弱暖 Fresnel，不描边
  • 人物 3.5 头身，圆肩圆头手脚略大；两颗圆点眼 + 一道眉；背心 / 绑腿 / 头巾可换色，枪口橙帽
  • 盒体顶面四角削倒角；每栋一种饱和哑光墙色（印厂灰蓝 / 渔村砖红），屋顶深一度；2–3 球团簇树
  • 实现：Toon + 片元噪声，成本≈Lambert，无后处理。风险：噪声偏大手机会显「脏」，按画质档可关
5

晶面海岬总监 B · 被海风吹干的彩色矿石岛

  • 低多边形晶面：所有几何平直法线，每个三角面独立明暗 + 顶点色抖动；冷色 Fresnel 边光显「透光」
  • 人物 5 头身修长，躯干六棱柱、四肢四棱、头切角八面体；深色护目镜带代替五官；胸前大块「板甲」色
  • 墙面按面微调色相；屋顶加斜切低多边形坡顶；三层六棱锥「宝石树」；海面正弦位移 + 平直法线碎玻璃光
  • 实现：非索引几何 + flatShading + 顶点色，比现在排线更省。风险：远处晶面闪烁，需按距离混平滑法线
6

套色印岛总监 B · 一张限量海报活过来了

  • 丝网 / 套色版画：亮部露米纸色，暗部用屏幕网点叠同色深版，阴影版整体偏移 1–2 px 做「套印不准」
  • 人物 4 头身宽肩短腿海报比例，头圆柱 + 盖帽；一片脸色版 + 两点眼；上衣单色 + 胸前几何徽标分阵营
  • 建筑只许「纸色 + 一版色 + 黑版阴影」三层，据点各用一版色（印厂蓝 / 渔村红 / 晒纸场橙黄）；三层椭圆盘印刷树
  • 实现：全部在材质片元内，无纹理无后处理。风险：网点与偏移需锁在物体空间，否则高速移动眩晕
7

咸风渔港总监 C · 亚热带渔港午后三点

  • 暖、懒、饱和：三阶 toon，太阳 4800 K 偏橙，阴影乘靛蓝，远景米黄雾；海扁平色块 + 顶点正弦浪
  • 人物 4.5 头身圆肩大头；两点眼 + 眉线；斗笠 / 头巾、无袖背心、卷脚裤，队伍色在腰带
  • 货栈靛蓝瓦 + 红木柱，渔村船漆三色，印厂褪色招牌，灯塔红白横条，采石场沙黄；伞形阔叶盘 + 椰叶三角扇
  • 实现：MeshToonMaterial + 4 px 程序渐变图，手机关阴影改脚底 blob。风险：米黄底上麦色人物对比弱，靠深色下装
8

雨季铁皮镇总监 C · 季风雨刚停的南洋小镇

  • 铅灰蓝阴天 + 浓绿 + 锈橙 / 亮黄两点：两阶 toon + 高光带，6500 K 冷柔光，阴影偏青，雾浓而近
  • 人物 5 头身瘦长；帽檐阴影下两点眼；连帽雨衣、胶靴、筒包，队伍色在雨衣袖口；亮黄雨衣兜底辨识
  • 全岛铁皮波纹顶（程序条纹法线），货栈集装箱色块，印厂青苔白墙，观测站黄栏杆；细高弯干椰树 + 芭蕉大叶
  • 实现：Toon + Fresnel 湿反光，雨用 200 条竖线随相机；无平面反射。风险：阴天低对比，远处 Bot 难辨
9

硫光黑滩总监 C · 火山岛傍晚的极简图形

  • 黑沙、硫黄、粉灰天：两阶硬 toon，3200 K 低角度暖光拉长影，阴影偏紫；黑 / 白 / 黄三色极简
  • 人物 4 头身敦实；护目镜 + 口罩省掉眼睛；砖红工装 + 黄反光条 + 头盔灯
  • 建筑一律白墙黑顶，据点靠黄门框区分；印厂黑铁皮，灯塔纯白，采石场硫黄纹理层；灰绿矮丛 + 枯白枝
  • 实现：地形顶点色按高度黑→灰，硫黄带程序噪声，色阶少手机最省。风险：黑底吃细节，物资掉落物必须描亮
